## このサイトについて

業務アプリの開発者が今のWeb開発の道具と技術を一から身につけるための教材です。Git や Docker のコマンドを打ったことがない人を想定しています。

最後に、次の構成の小さな業務アプリを自分で作れるようになることを目指します。

- 画面：TypeScript、React、React Router
- API：C#、ASP.NET Core
- データベース：PostgreSQL
- 動かす環境：Docker

## 進め方

- 上から順に、自分のペースで進めてください。前のレッスンで覚えたことを、次のレッスンで使います。
- 各レッスンの最後に「確かめよう」があります。書いてあるとおりの結果が出たら、次へ進んでください。
- 分からない言葉や出てきたエラーは、AI に説明してもらってかまいません。ただし、コマンドやコードは自分で打ってください。打った経験が次のレッスンで役に立ちます。

## レッスンの型

どのレッスンも次の順に書きます。

1. このページでできるようになること（3つまで）と、かかる時間の目安
2. 始める前に（前提になるレッスン）
3. なぜこれを覚えるのか（短く）
4. 本文：打つものと出てくる結果を、必ず対にして見せる
5. 困ったとき：よく出るエラーと、その意味
6. 確かめよう：本文の手順を少し組み替えた課題と、自分で答え合わせできる結果
7. 今は知らなくてよいこと
8. 次のレッスン

## 注意書きの使い分け

本文の流れから外れる情報は、次の4種類の注意書きに分けて書きます。

| 種類 | 使う場面 |
| --- | --- |
| note | 知っておくと安心な補足（表示の違いなど） |
| tip | 知らなくても進めるが、知っていると楽になる方法 |
| caution | 間違えやすい所や、やり直しに手間がかかる所 |
| danger | 元に戻せない操作。この種類は本当に戻せないときだけ使う |
