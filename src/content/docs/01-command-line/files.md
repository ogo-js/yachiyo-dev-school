## このページでできるようになること

- 絶対パスと相対パスを使い分けられる
- ファイルやフォルダをコピー・移動し、名前を変えられる
- 消す前に確かめてから、ファイルやフォルダを削除できる

かかる時間の目安は40分です。

## 始める前に

レッスン1-1（ターミナルで自分の居場所を知る）を「確かめよう」まで終えている必要があります。このレッスンではそのとき作った `practice` フォルダを使います。

## なぜこれを覚えるのか

開発では設定ファイルをコピーして書き換えたり、フォルダを整理したりすることがよくあります。手順書やエラーメッセージにも、ファイルの場所が「パス」という形でたびたび出てきます。パスが読めれば、エラーが何を指しているのかが分かります。

## 準備

練習用のフォルダに移動して、中身を確かめます。

```bash
cd ~/practice
ls
```

```text
lesson1  memo.txt
```

## パスの書き方

ファイルやフォルダの場所を表す書き方を「パス」と呼びます。パスには2つの書き方があります。

### 絶対パス

`/` から始まり、一番上から順にたどって書く方法です。どこにいても同じ場所を指します。

```bash
cat /home/yachiyo/practice/lesson1/hello.txt
```

```text
やちよ
```

`yachiyo` の部分は自分のユーザー名に、出てくる内容はレッスン1-1で書いた名前に置き換えて読んでください。

### 相対パス

今いる場所から見た道順で書く方法です。今は `/home/yachiyo/practice` にいるので、次のように短く書けます。

```bash
cat lesson1/hello.txt
```

```text
やちよ
```

同じファイルの中身が出ました。相対パスは短く書ける代わりに、今いる場所が変わると指す先も変わります。

### よく使う記号

| 記号 | 意味 | 例 |
| --- | --- | --- |
| `~` | 自分のホームフォルダ | `~/practice` は `/home/yachiyo/practice` と同じ |
| `.` | 今いるフォルダ | `./memo.txt` は `memo.txt` と同じ |
| `..` | 1つ上のフォルダ | `../practice` は、1つ上に出てから `practice` に入る |

:::tip[迷ったら絶対パス]
相対パスで「No such file or directory」と出たら、まず `pwd` で今いる場所を確かめてください。分からなくなったら、`~` から始めて書けば確実です。
:::

## コピーする：cp

`cp` は「コピー元」「コピー先」の順に書きます。

```bash
cp memo.txt memo-copy.txt
ls
```

```text
lesson1  memo-copy.txt  memo.txt
```

フォルダを中身ごとコピーするときは、`-r` を付けます。

```bash
cp -r lesson1 lesson1-backup
ls
```

```text
lesson1  lesson1-backup  memo-copy.txt  memo.txt
```

`-r` を付けないと、`-r not specified; omitting directory`（`-r` がないのでフォルダを飛ばした）と出て、コピーされません。

## 移動する・名前を変える：mv

`mv` も「元」「先」の順に書きます。名前を変えるときも、別のフォルダへ移すときも、同じ `mv` を使います。

まず、名前を変えます。

```bash
mv memo-copy.txt note.txt
ls
```

```text
lesson1  lesson1-backup  memo.txt  note.txt
```

次に、別のフォルダへ移します。行き先にフォルダの名前を書くと、その中へ移ります。

```bash
mv note.txt lesson1/
ls lesson1
```

```text
hello.txt  note.txt
```

:::caution[同じ名前があると上書きされます]
`cp` や `mv` の行き先に同じ名前のファイルがあると、確かめずに上書きします。上書きされた元のファイルは戻せません。心配なときは `-i` を付けると、上書きする前に聞いてくれます（例：`cp -i memo.txt lesson1/`）。
:::

## 削除する：rm

`rm` はファイルを削除するコマンドです。

:::danger[消したファイルは戻せません]
`rm` で消したファイルは、ごみ箱に入らずにすぐ消えます。元に戻す方法はありません。
:::

安全に消すために、次の順番を守ってください。

1. `ls` で、消すものの名前と場所を確かめる
2. `rm` で消す
3. もう一度 `ls` で、消えたことを確かめる

さっき移した `note.txt` を消します。

```bash
ls lesson1
```

```text
hello.txt  note.txt
```

```bash
rm lesson1/note.txt
ls lesson1
```

```text
hello.txt
```

フォルダを中身ごと消すときは、`rm -r` を使います。フォルダの中のものがすべて消えるので、`ls` で中身を確かめてから使ってください。

## 困ったとき

- **「Is a directory」や「-r not specified」と出た**：フォルダに対して、`-r` を付けずに `rm` や `cp` を使っています。フォルダを扱うときは `-r` を付けてください。
- **「No such file or directory」と出た**：パスが指す場所に、そのファイルやフォルダがありません。`pwd` と `ls` で、今いる場所と名前を確かめてください。
- **「Permission denied」と出た**：そのファイルを変える権限がありません。練習ではホームフォルダ（`~`）の中だけを使ってください。

## 確かめよう

`~/practice` にいる状態から、次のことをやってみてください。

1. `lesson2` というフォルダを作る
2. `lesson1/hello.txt` を、`lesson2` の中へ `greeting.txt` という名前でコピーする（1回の `cp` でできます）
3. `memo.txt` を `lesson2` の中へ移す
4. `lesson1-backup` を、中身を確かめてから消す
5. `lesson2` の中へ移動し、`lesson1` の `hello.txt` を相対パスで表示する（ヒント：`..`）

最後に、次の3つを打ちます。

```bash
ls ~/practice
ls ~/practice/lesson2
cat ~/practice/lesson2/greeting.txt
```

結果が次のようになり、`cat` で自分の名前が出れば完了です。

```text
lesson1  lesson2
greeting.txt  memo.txt
```

## 今は知らなくてよいこと

- `*` を使って、複数のファイルをまとめて指定する方法
- `sudo` を使って、管理者として操作する方法
- ファイルの権限を変える方法

どれも便利ですが、使い方を誤ると大きな失敗につながります。必要になったレッスンで、注意点と一緒に扱います。
