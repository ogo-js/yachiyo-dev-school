## このページでできるようになること

- VS Code でターミナルを開ける
- 今いるフォルダを確かめて、別のフォルダへ移動できる
- フォルダとファイルを作り、中身を見られる

かかる時間の目安は30分です。

## 始める前に

レッスン0-1（WSL2 を入れる）と0-2（VS Code を入れて WSL2 につなぐ）を終えている必要があります。

## なぜコマンドを覚えるのか

これから使う Git も Docker も、ふだんはターミナルに文字を打って動かします。マウスで操作する画面もありますが、手順書や質問の答えはほとんどがコマンドで書かれています。

難しく考える必要はありません。エクスプローラーでふだんしている「フォルダを開く」「中身を見る」「新しいフォルダを作る」を、文字で指示するだけです。

## ターミナルを開く

1. VS Code を開き、WSL に接続します。左下に「WSL: Ubuntu」と出ていれば接続できています。
2. 上のメニューから「ターミナル」→「新しいターミナル」を選びます。

画面の下に、次のような1行が出ます。

```text
yachiyo@pc:~$
```

これを「プロンプト」と呼びます。「ここにコマンドを打ってください」という合図です。左から順に、ユーザー名（`yachiyo`）、パソコンの名前（`pc`）、今いるフォルダ（`~`）を表しています。

`~` は「自分のホームフォルダ」の略です。ターミナルを開くと、まずここにいます。

:::note
この資料ではプロンプトの `yachiyo@pc:~$` の部分を省いて、打つコマンドだけを書きます。
:::

## 今いる場所を確かめる：pwd

次のように打って、Enter キーを押します。

```bash
pwd
```

```text
/home/yachiyo
```

`pwd` は「今いるフォルダの場所を表示する」コマンドです。`/home/yachiyo` が、さっきの `~` の正体です。`yachiyo` の部分は自分のユーザー名になっています。

## 中身を見る：ls

```bash
ls
```

今いるフォルダに入っているフォルダとファイルが並びます。何も表示されなければ、空っぽです。それで正常です。

## フォルダを作る：mkdir

練習用のフォルダを作ります。

```bash
mkdir practice
ls
```

```text
practice
```

`mkdir` は「フォルダを作る」コマンドです。もう一度 `ls` を打つと、`practice` ができているのが分かります。

## 移動する：cd

作ったフォルダの中へ移動します。

```bash
cd practice
pwd
```

```text
/home/yachiyo/practice
```

プロンプトも `~/practice$` に変わります。今いる場所が変わったことが、ここでも確かめられます。

ひとつ上のフォルダへ戻るときは、`..`（ドット2つ）を使います。

```bash
cd ..
pwd
```

```text
/home/yachiyo
```

どこにいても、`cd` とだけ打てばホームフォルダへ戻れます。迷子になったら、まず `cd` を打ってください。

:::tip[Tab キーで入力を補う]
`cd pra` まで打って Tab キーを押すと、`cd practice` と続きを補ってくれます。打ち間違いが減るので、慣れたら積極的に使ってください。
:::

## ファイルを作って、中身を見る

練習用のフォルダに入り、ファイルを1つ作ります。

```bash
cd practice
touch memo.txt
ls
```

```text
memo.txt
```

`touch` は「空のファイルを作る」コマンドです。

このファイルを VS Code で開きます。

```bash
code memo.txt
```

エディタでファイルが開きます。「こんにちは」と1行書いて、保存してください。

ターミナルに戻り、中身を表示します。

```bash
cat memo.txt
```

```text
こんにちは
```

`cat` は「ファイルの中身を表示する」コマンドです。エディタで書いた内容がターミナルからも見えました。

## エクスプローラーとの対応

| したいこと | エクスプローラー | ターミナル |
| --- | --- | --- |
| 今いる場所を知る | アドレスバーを見る | `pwd` |
| 中身を見る | フォルダを開く | `ls` |
| 新しいフォルダを作る | 右クリック →「新規作成」 | `mkdir 名前` |
| フォルダに入る | ダブルクリック | `cd 名前` |
| 1つ上に戻る | 「↑」ボタン | `cd ..` |
| ファイルを開く | ダブルクリック | `code 名前` |

## 困ったとき

- **「No such file or directory」と出た**：指定した名前のフォルダやファイルが、今いる場所にありません。`pwd` で場所を、`ls` で名前を確かめてください。
- **「command not found」と出た**：コマンド名を打ち間違えています。綴りを確かめてください。
- **何かが動き続けて止まらない**：Ctrl キーを押しながら C キーを押すと止まります。

## 確かめよう

次のことを、マウスを使わずにやってみてください。

1. ホームフォルダの下に `practice/lesson1` というフォルダを作る（`practice` の中に `lesson1` を作る）
2. `lesson1` の中に `hello.txt` を作り、VS Code で自分の名前を1行書いて保存する
3. ターミナルで次の2つを打つ

```bash
pwd
cat hello.txt
```

`pwd` の結果が `/home/自分のユーザー名/practice/lesson1` で、`cat` の結果に自分の名前が出れば完了です。

## 今は知らなくてよいこと

ターミナルには、ほかにもたくさんのコマンドがあります。このレッスンで扱わなかったものは、必要になったときに覚えれば十分です。

:::caution
ファイルを消す `rm` コマンドは、消したファイルがごみ箱に入らず、元に戻せません。使い方は後のレッスンで改めて扱います。それまでは、要らないファイルは VS Code の画面から消してください。
:::
