## このページでできるようになること

- Windows に VS Code を入れられる
- VS Code を WSL2 の Ubuntu につなげられる
- つながっているかどうかを、画面で見分けられる

かかる時間の目安は20分です。

## 始める前に

レッスン0-1（WSL2 を入れる）を終えている必要があります。

## なぜ VS Code を使うのか

VS Code（Visual Studio Code）は、プログラムや設定ファイルを書くためのエディタです。無料で使えて、この教材で扱う言語や道具のほとんどに対応しています。

VS Code は Windows に入れますが、WSL2 の Ubuntu につないで使えます。画面は Windows で動き、ファイルの読み書きやコマンドは Ubuntu の中で動きます。

## VS Code を入れる

1. ブラウザで VS Code の公式サイト（code.visualstudio.com）を開きます。
2. Windows 用のダウンロードのボタンを押し、インストーラーを保存します。
3. 保存したインストーラーを開き、画面の案内に沿って進めます。選択肢は最初から選ばれているままでかまいません。

:::note
VS Code は Windows に入れます。Ubuntu の中に入れる必要はありません。
:::

## 画面を日本語にする（好みで）

VS Code の画面は、最初は英語です。日本語にしたい場合は、次のようにします。

1. 左端の縦に並んだアイコンのうち、四角が4つ並んだ形のもの（拡張機能）を押します。
2. 上の検索欄に「Japanese」と入力します。
3. 「Japanese Language Pack for Visual Studio Code」の「Install」を押します。
4. 右下に再起動を求める表示が出たら、それを押して VS Code を開き直します。

この教材ではメニューの名前を日本語で書きます。英語のまま使う場合は、括弧の中の英語の名前を見てください。

## WSL の拡張機能を入れる

VS Code を Ubuntu につなぐには、「WSL」という拡張機能が必要です。

1. 拡張機能の画面を開き、検索欄に「WSL」と入力します。
2. 発行元が Microsoft の「WSL」を選び、「インストール」（Install）を押します。

## Ubuntu につなぐ

1. VS Code の画面の左下の端にある、青や緑の小さなボタンを押します。
2. 画面の上に一覧が出るので、「WSL への接続」（Connect to WSL）を選びます。

初めてつなぐときは、Ubuntu の中に必要なものが自動で入るので、少し時間がかかります。

つながると、左下のボタンに「WSL: Ubuntu」と表示されます。この表示があるときは、VS Code が Ubuntu の中で作業しています。

## 困ったとき

- **一覧に「WSL への接続」が出ない**：WSL の拡張機能が入っていません。前の手順に戻って入れてください。
- **つなぐときにエラーが出る**：Ubuntu が正しく入っていない可能性があります。レッスン0-1の「確かめよう」をもう一度試してください。

## 確かめよう

1. VS Code をいったん閉じて、開き直します。
2. 左下のボタンから、もう一度 Ubuntu につなぎます。
3. 上のメニューから「ファイル」→「フォルダーを開く」（File → Open Folder）を選びます。

上に出てくる場所の欄が `/home/自分のユーザー名/` になっていれば完了です。ここが Ubuntu の中の、自分のホームフォルダです。確かめたら、Esc キーで欄を閉じてかまいません。

## 今は知らなくてよいこと

VS Code にはたくさんの拡張機能があります。必要なものは使うレッスンでそのつど紹介します。
