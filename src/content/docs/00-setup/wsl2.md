## このページでできるようになること

- Windows に WSL2 と Ubuntu を入れられる
- Ubuntu のユーザー名とパスワードを決められる
- WSL2 が動いていることを確かめられる

かかる時間の目安は30分です（ダウンロードの速さによって変わります）。

## 始める前に

- Windows 11、または Windows 10 のバージョン 2004 以降が必要です。
- パソコンの管理者の権限が必要です。会社のパソコンで権限がない場合は、パソコンを管理している担当の人に相談してください。

## なぜ WSL2 を入れるのか

Web アプリの多くは、Linux のサーバーの上で動きます。開発で使う道具（Git や Docker など）も、Linux の上で使うことを前提に作られているものが多くあります。

WSL2（Windows Subsystem for Linux 2）を入れると、Windows のパソコンの中で Linux をそのまま動かせます。この教材では Linux の一種である Ubuntu を使います。

## PowerShell を管理者として開く

1. 画面下のスタートボタンを押し、「PowerShell」と入力します。
2. 出てきた「Windows PowerShell」を右クリックし、「管理者として実行」を選びます。
3. 「このアプリがデバイスに変更を加えることを許可しますか？」と聞かれたら、「はい」を選びます。

青か黒の画面が開きます。これが PowerShell です。

## WSL2 と Ubuntu を入れる

PowerShell に次のように打って、Enter キーを押します。

```powershell
wsl --install
```

必要なものの取得とインストールが始まります。途中で止まっているように見えても、終わるまで待ってください。

インストールが終わったら、パソコンを再起動します。

## Ubuntu のユーザー名とパスワードを決める

再起動すると、Ubuntu の画面が自動で開きます。開かない場合は、スタートボタンを押して「Ubuntu」と入力し、出てきた「Ubuntu」を開いてください。

しばらく待つと、ユーザー名を聞かれます。

```text
Enter new UNIX username:
```

半角の英小文字で、短い名前を打ちます（例：`yachiyo`）。Windows のユーザー名と同じでなくてかまいません。

続けて、パスワードを2回聞かれます。

```text
New password:
Retype new password:
```

:::caution[パスワードは打っても画面に出ません]
パスワードを打っている間、画面には何も表示されません。`*` も出ません。これは故障ではなく、周りの人に見られないための仕組みです。そのまま最後まで打って、Enter キーを押してください。
:::

このパスワードは後のレッスンで使います。忘れないように控えておいてください。

次のような1行が出れば、Ubuntu の準備はできています。

```text
yachiyo@pc:~$
```

Ubuntu の画面は右上の「×」で閉じてかまいません。

## 困ったとき

- **「仮想化」や「Virtual Machine Platform」についてのエラーが出た**：パソコンの設定で、仮想化の機能が止められています。パソコンを管理している担当の人に相談してください。
- **再起動しても Ubuntu の画面が出ず、スタートメニューにも「Ubuntu」がない**：Ubuntu が入らなかった可能性があります。PowerShell を管理者として開き、`wsl --install -d Ubuntu` と打ってください。`-d Ubuntu` は「Ubuntu を入れる」という指定です。
- **「wsl」が見つからないと出た**：Windows のバージョンが古い可能性があります。「設定」→「Windows Update」で更新してから、もう一度試してください。
- **パスワードを打ち間違えて先に進めない**：もう一度聞かれるので、落ち着いて打ち直してください。

## 確かめよう

PowerShell を開き（今回は管理者でなくてかまいません）、次のように打ちます。

```powershell
wsl -l -v
```

次のように、`Ubuntu` の行の `VERSION` が `2` になっていれば完了です。

```text
  NAME      STATE           VERSION
* Ubuntu    Stopped         2
```

`STATE` は `Stopped` でも `Running` でもかまいません。
